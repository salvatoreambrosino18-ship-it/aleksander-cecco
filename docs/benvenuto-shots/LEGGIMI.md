# Le quattro fotografie del pannello

Servono per fargli riconoscere quello che sta guardando, e per farle bisogna
entrare nel pannello con le sue credenziali.

Mettile qui con questi nomi esatti e rilancia `npm run welcome-pdf`.

    1-schermata-iniziale.png    la prima schermata, quella che dice «Il tuo sito»
    2-prezzo-e-taglie.png       un capo aperto, con il prezzo e le taglie in cima
    3-fotografie.png            le fotografie del capo, dove si trascinano
    4-publish.png               il pulsante Publish, in basso a destra

Larghezza consigliata 1400 pixel, PNG. Senza questi file il PDF si costruisce lo
stesso e la sezione non compare, il che è meglio di quattro riquadri vuoti.
